mezclar(canciones, cunas) → {Array.<Object>}

Genera una lista intercalada siguiendo un ratio por tipo: - Calcula un ratio canciones/cuñas: - ratio = canciones.length / cunas.length - Se limita entre: - mínimo: 1 - máximo: 3 - Calcula un ratio cuñas/canciones: - ratio = cuñas.length / canciones.length - Se limita entre: - mínimo: 1 - máximo: 2 - Inserta elementos en el siguiente orden: - Inserta la cantidad del ratio en canciones - Inserta la cantidad del ratio en cuñas - Repite hasta agotar ambas listas y agrega el exceso al final
Parameters:
Name Type Description
canciones Array.<Object> Lista de canciones
cunas Array.<Object> Lista de cuñas (anuncios)
Source:
  • componentes/audio_data.js, line 461
Returns:
Lista final mezclada
Type
Array.<Object>
Example
// Ejemplo:
canciones = [C1, C2]
cunas = [A1, A2, A3, A4]

// ratio canciones = 3
// ratio cuñas = 2
resultado = [C1, A1, A2, C2, A3, A4]
